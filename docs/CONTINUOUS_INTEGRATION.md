# Continuous-scan integration

## Player behavior

Select **Scan + select** and start automatic scanning once. In Beacon Steps, scanning continues after each deliberately confirmed move until the game ends or scanning is paused. Highlight changes alone never advance the game.

In Pocket Signals, committing a card covers the hand and stops the timer for the handoff. The next player deliberately reveals their own hand with a fresh activation; scanning then resumes. A held or repeated activation must not both reveal a hand and commit its first choice. Release the key before the next deliberate action. Pause remains available, and manual stepping does not require automatic scanning. Changing games, changing access packs, opening a pack, or entering the workshop cancels automatic scanning.

These controls qualify a bounded action-selection mechanism after setup. They do not establish whole-application single-switch access, physical-switch compatibility, screen-reader usability, or benefit in human access playtests. Local pass-and-play still requires a trusted device and cooperative players.
